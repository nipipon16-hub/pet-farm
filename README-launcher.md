# ตัวเปิดแอป: ไอคอนบนหน้าจอหลัก (ฟาร์มสัตว์เลี้ยงประจำห้อง)

## ทำไมต้องมีตัวเปิดแอป

เว็บที่อยู่บน Google Apps Script **ติดตั้งเป็นแอปเต็มตัว (PWA) ด้วยตัวเองไม่ได้** เพราะ Google ครอบหน้าเว็บไว้ในกรอบอีกชั้นหนึ่ง และเราแก้หัวหน้าเว็บชั้นนอกไม่ได้
(ไอคอนบนหน้าจอหลักของ iPhone และ Android อ่านจากหัวหน้าเว็บชั้นนอกนี้) ถ้ากด "เพิ่มลงหน้าจอหลัก" จากลิงก์ Apps Script ตรงๆ จะได้ไอคอนทั่วไป (iPhone มักได้ตัวอักษรหรือภาพหน้าจอ)

วิธีแก้คือใช้ **ตัวเปิดแอป** เว็บเล็กๆ 1 หน้า ที่มีไอคอนของคุณครบทุกขนาด วางบนบริการฟรี แล้วให้ผู้ใช้เพิ่มหน้านี้ลงหน้าจอหลักแทน
เมื่อกดไอคอน จะเห็นหน้าโหลดสั้นๆ แล้วพาเข้าระบบจริงบน Apps Script ให้เอง

## ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าตัวเปิดแอป (มีค่าที่ต้องแก้ 1 ค่า: `APP_URL`) |
| `manifest.webmanifest` | ข้อมูลแอป ชื่อ สี ไอคอน (ทำให้ Chrome ติดตั้งเป็นแอปได้) |
| `sw.js` | service worker ขั้นต่ำ ที่เบราว์เซอร์ต้องการสำหรับการติดตั้ง |
| `icons/` | ไอคอนทุกขนาดที่ทำจากไฟล์ที่แนบมา |

ไอคอนใน `icons/`
- `icon-512.png`, `icon-192.png` — ไอคอนปกติ (มุมโปร่งใส)
- `icon-maskable-512.png`, `icon-maskable-192.png` — แบบเต็มพื้นที่ สำหรับ Android ที่ตัดไอคอนเป็นวงกลมหรือสี่เหลี่ยมมน (ภาพหลักอยู่ในโซนปลอดภัย 80%)
- `apple-touch-icon.png` (180×180) — ไอคอนของ iPhone/iPad
- `favicon-16/32/48/64.png`, `favicon.ico` — ไอคอนบนแท็บเบราว์เซอร์
- `logo-96.png` — ใช้เป็นโลโก้ในหัวเว็บ (ฝังในไฟล์ `Index.html` ของระบบแล้ว)

> ไอคอนต้นฉบับ (แมวและสุนัขถือใบคะแนน) เป็นสี่เหลี่ยมมนบนพื้นขาวมีเงา ผมตัดพื้นขาวและเงาออกให้โปร่งใส และสร้างแบบเต็มพื้นที่โดยต่อพื้นไล่สีน้ำเงินให้เข้ากับขอบไอคอน
> ในแบบเต็มพื้นที่อาจเห็นขอบมนจางๆ ถ้าต้องการให้เนียนกว่านี้ ส่งไฟล์ต้นฉบับแบบเต็มสี่เหลี่ยม (ไม่มีมุมมน ไม่มีพื้นขาว) มาได้

## ขั้นตอนติดตั้งให้ใช้งานได้

### 1) ใส่ลิงก์ระบบ
เปิด `index.html` หาบรรทัด `const APP_URL = '';` ใส่ **ลิงก์ A** (ลิงก์หน้าต้อนรับที่เปิดให้ทุกคน) เช่น
```js
const APP_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```
(ถ้าอยากเปลี่ยนชื่อแอปหรือคำอธิบาย แก้ `APP_NAME` กับ `APP_TAGLINE` ในที่เดียวกัน และแก้ `name` / `short_name` ใน `manifest.webmanifest` ให้ตรงกัน)

### 2) วางโฟลเดอร์นี้บนเว็บ (ต้องเป็น HTTPS) เลือกอย่างใดอย่างหนึ่ง
- **Cloudflare Pages**: สร้างโปรเจกต์ใหม่แบบ "Direct Upload" แล้วลากโฟลเดอร์ `pet-class-launcher` ไปวาง
- **Netlify**: ไปที่หน้า Sites แล้วลากโฟลเดอร์ไปวาง (Drag and drop)
- **GitHub Pages**: สร้างที่เก็บ (repository) อัปโหลดไฟล์ทั้งหมด แล้วเปิด Settings > Pages เลือก branch main

ได้ที่อยู่เว็บเช่น `https://ชื่อ.pages.dev/` ให้เปิดดูว่าเห็นหน้าที่มีไอคอนกับปุ่ม "เปิดแอป"

### 3) แจกลิงก์ตัวเปิดแอปให้นักเรียนและครู แล้วให้เพิ่มลงหน้าจอหลัก
- **iPhone / iPad**: เปิดลิงก์ด้วย **Safari** > กดปุ่มแชร์ > เลือก "เพิ่มไปยังหน้าจอโฮม"
- **Android**: เปิดด้วย **Chrome** > กดเมนู ⋮ > "ติดตั้งแอป" (หรือกดปุ่ม "ติดตั้งเป็นแอปบนเครื่องนี้" ในหน้านั้นถ้าขึ้น)
- **คอมพิวเตอร์**: Chrome หรือ Edge กดไอคอนติดตั้งท้ายช่องที่อยู่เว็บ

หลังติดตั้ง กดไอคอน จะเห็น "กำลังเปิดแอป..." แล้วเข้าระบบเลย (ถ้ายังไม่ได้ล็อกอิน Google จะพาไปหน้าลงชื่อเข้าใช้ก่อน)

## ไอคอนบนแท็บเบราว์เซอร์ของตัวระบบ (แทนสัญลักษณ์ Apps Script)

สัญลักษณ์ Apps Script บนแท็บมาจากหน้าชั้นนอกของ Google ต้องตั้งผ่านคำสั่ง `setFaviconUrl` ของ Apps Script เท่านั้น (แท็กไอคอนที่ฝังในไฟล์ HTML ของเราถูก Google เมินตามเอกสาร)
Google กำหนดว่า **ลิงก์ต้องเป็น https ที่เปิดดูได้สาธารณะ และลงท้ายด้วยนามสกุลภาพ เช่น `.png`** ลิงก์ Google Drive แบบ `uc?id=...` ไม่มีนามสกุล จึงใช้ไม่ได้

1. วางไฟล์ `icons/favicon-64.png` (หรือ `favicon.png` ที่แนบมา) บนเว็บที่ได้ลิงก์ลงท้าย `.png` เช่นตัวเปิดแอปในข้อ 2 จะได้ `https://ชื่อ.pages.dev/icons/favicon-64.png`
   (หรือจะอัปโหลดไฟล์ไปที่ GitHub แล้วใช้ GitHub Pages ก็ได้)
2. เปิดชีตของระบบ แท็บ **Settings** หาแถว **`favicon_url`** แล้ววางลิงก์ในช่อง value
3. รีเฟรชหน้าระบบ (มีผลภายใน 5 นาที ไม่ต้อง Deploy ใหม่) ถ้ายังเห็นไอคอนเดิม ให้ปิดแท็บแล้วเปิดใหม่หรือกด Ctrl+Shift+R เพราะเบราว์เซอร์จำ favicon ไว้นาน

ถ้าลิงก์ไม่ถูกต้อง (ไม่ใช่ https หรือไม่มีนามสกุลภาพ) ระบบจะข้ามไปเฉยๆ ไม่ทำให้หน้าเว็บพัง

## ข้อจำกัดที่ควรรู้
- **ระบบจริงยังต้องออนไลน์**: ตัวเปิดแอปเปิดได้แม้ไม่มีเน็ต แต่ตัวระบบอยู่บน Google
- **บน iPhone/Android** เมื่อกดไอคอนแล้วระบบเปิดในหน้าที่ออกนอกขอบเขตของแอป อาจมีแถบเล็กๆ ด้านบน (เช่น "เสร็จสิ้น" บน iPhone หรือแถบที่อยู่เว็บบน Android) เป็นข้อจำกัดของ Apps Script ที่แก้ไม่ได้ ผมยังไม่ได้ทดสอบบนเครื่องจริงของทั้งสองระบบ
- แก้ไฟล์ในโฟลเดอร์นี้แล้ว ให้เปลี่ยนเลข `CACHE = 'launcher-v1'` ใน `sw.js` เป็น `v2` เพื่อให้เครื่องที่ติดตั้งไว้รับของใหม่
